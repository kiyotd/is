スクロールやデバイス判定に応じて、bodyに以下のクラスが付与されます：

  • is-scrolled - 一定量スクロールした時
  • is-scroll-top - ページトップ付近にいる時
  • is-scroll-up - 上方向にスクロールした時
  • is-scroll-down - 下方向にスクロールした時
  • is-android / is-iphone / is-ipad / is-pc - デバイス判定
  • is-chrome / is-firefox / is-safari / is-ie / is-edge - ブラウザー判定

開発者ツールでbody要素のクラスを確認しながらスクロールしてみてください。
